# bit-set (Kinogaki)

Ours, not upstream bit-set. It is published under the crates.io name
(`0.10.0+kinogaki`) for the frozen naga and wgpu-core.

It is a set of small integers stored as our `BitVec`, with insert, remove,
the set operations and ascending iteration. Safe code. tests/sets.rs covers
both crates.
