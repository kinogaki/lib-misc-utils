# kinogaki-unicode

Unicode text segmentation for Kinogaki's text editing and layout:

- `graphemes` / `grapheme_indices`: extended grapheme clusters (UAX #29);
- `word_bound_indices`: word boundaries (UAX #29);
- `is_mark`: combining marks (General_Category Mn, Mc, Me).

The tables (src/tables.rs) are generated by tools/generate.py from the
Unicode 17.0.0 UCD files in ucd/. Those files are © Unicode, Inc. and
distributed under the Unicode License v3; see the header of each file.

The tests run the UCD's own GraphemeBreakTest.txt and WordBreakTest.txt
(tests/conformance.rs). tests/tables.rs checks every code point's properties
against the UCD files, so a stale table fails.

To update: replace the ucd/ files, change `VERSION` in tools/generate.py, and
run `python3 tools/generate.py`.
