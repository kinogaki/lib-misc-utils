# lib-misc-utils: notes for agents

- Upstream-named crates exist so the frozen wgpu, naga, harfrust, hashbrown,
  blake3 and cc build unedited. Implement only what they call. A new call
  after a re-freeze shows up as a compile error, and the fix is to add it
  with a test. Never edit the frozen consumers to fit.
- Keep upstream's semantics where a consumer can observe them: conversion
  rules, rounding, hash values (rustc-hash), lock fairness (parking_lot),
  diagnostic text (codespan-reporting). Each crate's tests pin them.
- Unsafe is forbidden except arrayvec's src/buffer.rs and parking_lot's
  src/rwlock/cell.rs. Each block there states its safety argument.
- Generated tables are regenerated by the tools/ script next to them, never
  edited by hand. Their tests check them against their sources.
- Gates: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`
  and `cargo test --workspace`. Studio's `tools/check_all.py` runs them.
